# 오늘의 뉴스 클리핑 만들기

## 순서

1. 키워드.md 와 출처.md 를 읽는다.
2. 출처.md 에 적힌 곳에서 키워드마다 오늘 나온 기사를 모은다.
3. 마케팅팀이 아침에 읽을 만한 기사를 고른다. 같은 소식을 다룬 기사는 하나만 남긴다.
4. 고른 기사마다 제목, 언론사, 날짜, 쉬운 말 요약, 원문 링크를 정리한다.
5. clips/YYYY-MM-DD.html 에 오늘 날짜로 저장한다. 같은 날 파일이 이미 있으면 덮어쓰지 말고 -2, -3 을 붙여 새로 저장한다. 지난 클리핑처럼 브라우저로 보기 좋은 웹 페이지로 만든다.
6. clips/index.html 목록 맨 위에 새 클리핑 한 줄을 지난 줄과 같은 꼴(날짜, 기사 수, 오늘의 소식 첫 줄)로 더한다.

## 마지막 답

끝나면 아래 세 가지를 남긴다.

- 모은 기사 수
- 오늘의 소식 세 줄
- 저장한 파일 위치
