# 디자인 규칙

토스 앱의 결을 따른다. 값은 `src/lib/theme.ts` 에 있다.

## 여백

- 화면 좌우 24. 목록 줄은 위아래 12, 거래 내역 줄 높이 56.
- 다른 묶음은 16 높이의 회색 띠(#F2F4F6)로 가른다. 구분선과 카드를 겹쳐 쓰지 않는다.
- 여백은 8의 배수로 잡는다.

## 글자

| 쓰임                 | 크기    | 굵기 |
| -------------------- | ------- | ---- |
| 탭 화면 제목         | 26      | 700  |
| 단지 이름(단지 화면) | 22      | 700  |
| 큰 가격              | 30      | 700  |
| 묶음 제목            | 20      | 700  |
| 목록 이름·가격       | 17      | 600  |

숫자는 같은 폭(tabular-nums)으로 그린다. 가격은 오른쪽에 맞춘다.

## 색

- 글자는 회색 단계를 쓴다: 본문 #191F28, 보조 #4E5968, 흐림 #6B7684·#8B95A1, 꺼짐 #B0B8C1.
- 주 색 #3182F6 은 차트와 주 버튼에만 쓴다. 고른 탭·칩은 먹색(#191F28)이다.
- 하트(관심 단지)는 #F04452 다.
- 바탕은 흰색, 옅은 면은 #F2F4F6·#F9FAFB, 건물 그림 칸은 #F2F6FF 다.

## 플랫폼

- 아이폰: 뒤로 꺾쇠(‹), 흰 탭 바에 위 선, 꺼진 탭은 #B0B8C1.
- 안드로이드: 뒤로 화살표(←), 둥근 검색창, 고른 탭 아이콘 뒤에 알약 표시(#E5E8EB), 탭 바 바탕 #F9FAFB.

## 그림

- 건물 그림은 `src/components/buildingXml.ts` 의 입체 그림 두 개(단지·건물 하나)만 쓴다. 단지 화면과 빈 화면에 크게, 목록 칸에 작게 둔다.
- 아이콘은 `src/components/Icons.tsx` 의 선 아이콘 한 세트만 쓴다. 이모지를 쓰지 않는다.
