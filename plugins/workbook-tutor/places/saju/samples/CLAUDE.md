# 사주풀이

## 이 서비스

생년월일시를 넣으면 사주 여덟 글자와 풀이를 보여 주는 웹이에요. 폰으로 여는 사람이 많아서 폰 화면을 먼저 맞춰요.

| 화면      | 무엇                                                                                                   |
| --------- | ------------------------------------------------------------------------------------------------------ |
| 입력      | 양력·음력, 생년월일, 태어난 시각(모르면 「시각을 몰라요」)                                             |
| 결과      | 일주와 한 줄 요약, 여덟 글자와 십성, 오행, 풀이(성격·일과 돈·사람 관계), 올해와 내년, 없는 기운 채우기 |
| 십성 설명 | 결과에서 여는 아래 시트                                                                                |

| 파일               | 무엇                                                           |
| ------------------ | -------------------------------------------------------------- |
| `app/page.tsx`     | 입력과 결과를 한 주소에서 바꿔 보여 준다                       |
| `components/`      | 입력(`BirthForm`), 결과(`Result`), 십성 설명 시트(`GodsSheet`) |
| `lib/saju.ts`      | 여덟 글자 계산(만세력). 시각은 30분 보정한다                   |
| `lib/saju.test.ts` | 계산 확인. `npm test`                                          |
| `lib/readings.ts`  | 미리 적어 둔 풀이 문장                                         |

## 규칙

- 여덟 글자는 `lib/saju.ts` 가 계산한다. AI 나 손으로 계산하지 않는다. 계산을 고치면 `npm test` 를 돌린다.
- 생년월일시를 주소(URL)·링크·기록에 드러내지 않는다. 남의 생일과 태어난 시각이다.
- 화면을 바꾸면 `DESIGN.md` 를 따른다.
- 풀이 문장은 죽음·병을 단정하지 않고, 투자·결혼 같은 결정을 대신 내리지 않는다.
