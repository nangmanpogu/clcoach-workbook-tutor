# 발표 자료 디자인 규칙

장표를 만들기 전에 이 파일을 읽고 따른다. 장표 틀(장표-틀.pptx)에 정해 둔 바탕·판·선·칸의 자리와 크기는 바꾸지 않는다. 칸에는 글을 넣고, 그림은 그림 폴더의 PNG 를 아래 「그림」의 자리에 놓는다.

## 틀 고르기

| 틀        | 언제                                                                    | 칸                                                              |
| --------- | ----------------------------------------------------------------------- | --------------------------------------------------------------- |
| 표지      | 첫 장. 파란 바탕에 발표의 결론을 제목으로 쓴다                          | 머리말, 제목, 부제                                              |
| 결론      | 표지 다음 장. 결론을 받치는 숫자 셋                                     | 머리말, 제목, 이름·숫자 셋                                      |
| 전후      | 하나가 좋아진 전과 후. 왼쪽 회색 판이 전, 오른쪽 파란 판이 후           | 머리말, 제목, 왼쪽 숫자, 오른쪽 숫자, 출처                      |
| 전후 경고 | 하나가 나빠진 전과 후. 오른쪽 판이 빨갛다                               | 전후와 같다                                                     |
| 나눔      | 한 덩어리를 셋으로 나눈 것(설문 답). 가장 큰 몫이 왼쪽 넓은 파란 판이다 | 머리말, 제목, 이름·숫자·덧붙임 셋, 출처                         |
| 셈        | 「가 − 나 = 다」로 계산이 보이는 돈. 결과 판이 빨갛다                   | 머리말, 제목, 이름·숫자 셋, 덧붙임 한 줄, 출처                  |
| 층별      | 건물의 층마다 다른 것. 왼쪽에 층 단면, 오른쪽에 층별 문제와 보완 둘     | 머리말, 제목, 층·내용·표시 셋, 오른쪽 머리·본문·덧붙임 둘, 출처 |
| 견주기    | 두 안을 항목 셋으로 견준다. 오른쪽이 제안하는 안이다                    | 머리말, 제목, 왼쪽·오른쪽 머리, 항목·왼쪽·오른쪽 셋, 출처       |
| 맺음      | 마지막 장. 어두운 바탕에 듣는 사람이 정할 것 셋과 제안                  | 머리말, 제목, 정할 것·제안 셋                                   |

- 틀마다 칸 이름을 적은 보기 장이 장표-틀.pptx 에 한 장씩 있다. 칸 번호는 그 장에서 읽는다.
- 쓰지 않는 칸은 지운다. 빈 칸을 남기지 않는다.
- 쪽 번호 칸(번호 40)에는 장 번호를 글로 적는다. 표지와 맺음에는 없다.

## 장 짜임

- 한 장에 말하고 싶은 것은 하나다.
- 머리말은 무엇을 센 장인지와 단위를 짧게 쓴다(「일회용 컵 · 평일 하루 평균」).
- 제목은 그 장의 결론을 한 문장으로 쓴다. 「현황」「개요」「목차」처럼 이름만 붙이지 않는다.
- 제목이 두 줄이면 뜻이 끊기는 곳에서 직접 줄을 바꾼다(`\v`). 맡겨 두면 낱말 가운데서 끊길 수 있다.
- 「감사합니다」 장은 만들지 않는다.

## 숫자 칸

- 전후·전후 경고의 숫자 칸에는 이름과 숫자를 한 줄에 쓴다(「8월 · 시범 전 412개」). 칸의 글자는 숫자 크기라서, 이름 부분만 13.5pt `Pretendard SemiBold` 로 줄인다. 이름 색은 왼쪽 #8B95A1, 오른쪽 #3182F6, 전후 경고의 오른쪽 #F04452 다.
- 숫자에는 단위를 붙인다(412개, 62%, 135만원).
- 숫자는 자료 폴더의 문서에 적힌 것과 같아야 한다. 그림을 그리려고 숫자를 새로 만들지 않는다.

## 그림

그림 폴더의 PNG 를 쓴다. 장에 맞는 그림이 없으면 그리지 말고 그림 없이 둔다. 자리는 1280×720 화면의 px 이다(1px = 9525 EMU). 그림은 표의 크기 그대로 놓는다.

| 그림                                      | 크기(px)  | 어느 틀   | 자리                                                                              |
| ----------------------------------------- | --------- | --------- | --------------------------------------------------------------------------------- |
| 표지-컵                                   | 200 × 268 | 표지      | (928, 356)                                                                        |
| 컵-회색, 컵-파랑                          | 80 × 62   | 전후      | 포개 쌓기(아래). 왼쪽 판은 회색, 오른쪽 판은 파랑                                 |
| 작은컵-회색, 작은컵-진회색, 작은컵-빈자리 | 36 × 44   | 전후 경고 | 늘어놓기(아래)                                                                    |
| 쓰레기통-넘침, 반납함-정돈                | 150 × 150 | 전후      | 왼쪽 (285, 310), 오른쪽 (845, 310)                                                |
| 사람-파랑, 사람-회색                      | 30 × 45   | 나눔      | 판 왼쪽 위 (판 x + 36, 284) 부터 38px 간격. 판 x 는 112·640·912. 파랑은 첫 판에만 |
| 세척-컵, 일회용-컵, 돈-빨강               | 88 × 88   | 셈        | (228, 318), (596, 318), (964, 318)                                                |
| 반납함-파랑, 반납함-빨강                  | 22 × 22   | 층별      | 표시 칸 왼쪽 (452, 346), (452, 442), (452, 538). 빨강은 표시 글자가 빨간 줄에만   |
| 아이콘-달력, 아이콘-반납함, 아이콘-컵     | 32 × 32   | 맺음      | 정할 것 왼쪽 (124, 416), (124, 496), (124, 576)                                   |

- **포개 쌓기:** 하나가 50개다(412개면 8개, 268개면 5개, 반올림). 판 가운데(왼쪽 판 x 360, 오른쪽 판 x 920)에 맞춰, 맨 아래 그림의 아래 끝이 y 460 에 닿게 놓는다. 하나 올라갈 때마다 18px 위로 간다. 위의 것부터 놓아 아래 것이 앞에 보이게 한다.
- **늘어놓기:** 하나가 50개다. 판 가운데에 168 × 194 자리를 잡고(아래 끝 y 460), 아래 줄부터 4·3·2·1 개로 놓는다. 자리 안의 좌표는 (0,150) (44,150) (88,150) (132,150) (22,100) (66,100) (110,100) (44,50) (88,50) (66,0) 이다. 줄어든 몫은 작은컵-빈자리 로 채워, 원래 몇 개였는지가 보이게 한다.
- 그림을 쓴 장은 출처 칸에 그림 하나가 얼마인지 적는다(「컵 그림 하나 = 50개」).

- 파랑과 빨강은 뜻이 있을 때만 쓴다. 꾸미려고 쓰지 않는다.
- 나쁜 소식인 글은 칸의 글자 색만 #F04452 로 바꾼다(결론의 「108만원 더」, 층별의 「1층」). 판 색은 틀로 고른다(전후 경고, 셈).

## 글꼴

- Pretendard 하나만 쓴다. 굵기는 보통(Regular), 중간(SemiBold), 굵게(Bold) 셋이다. 중간 굵기는 글꼴 이름을 `Pretendard SemiBold` 로 적어 고른다.
- 크기와 굵기는 틀에 정해져 있으니 칸에 글만 넣는다. 바꾸는 것은 위 「숫자 칸」의 이름 부분뿐이다.

## 출처

- 숫자가 나오는 장에는 아래쪽 출처 칸에 어느 자료에서 왔는지 적는다(예: 「시범 운영 보고서」, 「이용자 설문 186명」). 계산식은 적지 않는다.
- 추정이거나 확인이 필요한 것은 그대로 적는다(「(추정)」, 「(확인 필요)」).

- 「혁신」「시너지」「한눈에 보는」 같은 꾸밈말
