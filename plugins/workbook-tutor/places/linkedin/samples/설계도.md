# 설계도: 링크드인 연락 비서

| 칸 | 내용 |
| --- | --- |
| 한 줄 요약 | 매일 아침 오늘 연락할 사람을 골라 짧은 노트를 써 두면, 내가 읽고 링크드인에서 보낸다 |
| 언제 시작하나 | 매일 아침 |
| 무엇을 읽나 | 1촌 목록(1촌-목록/Connections.csv), 내가 고른 프로필(고른-프로필 폴더), 연락할 사람 기준(연락할-사람-기준.md), 말투 폴더 |
| 무엇을 하나 | 기준대로 점수를 매겨 오늘 연락할 사람을 고르고, 사람마다 250자 안쪽 노트를 쓴다. 하루에 보낼 개수를 정해 둔다 |
| 어디에 남기나 | 구글 시트 |
| 내가 하는 일 | 노트를 읽고 고친 뒤 링크드인에서 직접 보낸다. 수락과 답장이 오면 시트에 표시한다 |
| 조심할 일 | 남에게 가는 일: 링크드인 메시지와 1촌 신청은 클코가 보내지 않는다. 비밀값: 링크드인 로그인은 클코에게 맡기지 않는다 |
| 지금 단계 | 손으로: 매번 프로필을 열어 보고 노트를 처음부터 쓴다 |
| 목표 단계 | 알아서: 매일 아침 준비돼 있고, 나는 보내기만 누른다 |
| 작업 완료 기준 | 오늘 연락할 사람마다 이름·회사·고른 이유·노트·프로필 주소가 있다. 노트는 250자 안쪽이다 |
| 읽을 기술 장 | AI 티 안 나는 글 쓰기, 좋은 스킬 만들기, 앱을 직접 조작하기 |
