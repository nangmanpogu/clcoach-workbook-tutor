# 학습 도우미

「클코 학습지」를 따라 할 때 Claude Code 에 까는 플러그인이에요. 막힌 단계를 돕고, 내가 한 단계를 학습지에 「봤어요」로 알려 줘요.

## 설치

학습지 1-1 의 3절에 있는 한 줄을 복사해 붙여 넣어요. Mac 은 터미널, Windows 는 PowerShell 이에요. 줄 끝에 내 학습지 계정의 설치 코드가 붙어 있어서 학습지에서 복사해야 해요.

설치 줄([install.sh](install.sh), [install.ps1](install.ps1))은 Claude Code 설정에 도우미를 더하고 학습지 계정과 이어요. Windows 는 Git for Windows 가 없으면 먼저 깔아요.

도우미는 학습지를 산 계정에서만 학습지 서버에 연결해요. 구매가 확인되지 않으면 하루 한 번 알려 드려요. 학습지에서 구매를 확인하면 설치를 다시 하지 않아도 이어져요.

## 명령

| 명령        | 하는 일                                                                                                                                                                                                                                                                                                                                                                                            |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/막혔어`   | 학습지의 「막혔어요」가 복사해 준 문장을 보내면 다음 한 걸음을 알려 줘요                                                                                                                                                                                                                                                                                                                           |
| `/시작`     | 1권 2부 첫 장(2-1)에서 Node.js 를 깔고 연습 재료를 넣어요. 2권은 `/시작 뉴스 클리핑`(빈 폴더에 연습 파일을 넣어요)과 `/시작 내 업무`(지금 폴더를 그대로 써요), 3부 예시마다 `/시작 문의 답장` 같은 이름이에요. `/시작 발표 자료` 는 장표 틀의 글꼴도 설치해요. `/시작 경쟁사 알림` 은 학습지 서버에서 지난 버전도 받아요. 3권은 `/시작 3권` 이 뉴스 클리핑 폴더를 git 으로 저장할 수 있게 준비해요 |
| `/학습지`   | 하던 장을 Claude 앱 안의 브라우저에 로그인한 채로 열어요                                                                                                                                                                                                                                                                                                                                           |
| `/질문`     | 학습지 내용(개념의 뜻, 몇 장에서 배웠는지, 지난 장 요약)과 도우미 기능을 물으면 학습지 원고로 답해요. 이 폴더에서 연 지난 세션도 찾아봐요                                                                                                                                                                                                                                                          |
| `/연습청구` | 3권 3-5 에서 비용 표를 만들 연습 청구 메일을 내 메일 주소로 받아요. 처음에는 지난 석 달 치 아홉 통, 그 뒤로는 한 통이에요. 실제 결제가 아닌 연습 메일이라고 적혀 있어요. 3권 폴더를 모은 projects 폴더에서 보내요                                                                                                                                                                                  |
| `/명령규칙` | 3권 3-3 에서 서비스 기록을 읽는 명령을 클코에게 만들어 달라고 하면 클코가 저절로 따르는 규칙이에요. 결과는 JSON 으로, 필요한 만큼만 읽고, 토큰은 내 컴퓨터의 설정 파일에만 두고, 읽기만 해요                                                                                                                                                                                                       |
| `/연습문의` | 2권 3부 문의 답장 예시에서 연습 문의 메일을 내 메일 주소로 받아요. 처음에는 다섯 통, 그 뒤로는 한 통이에요. `/시작 문의 답장` 을 보낸 폴더에서만 보내요                                                                                                                                                                                                                                            |

`/시작 경쟁사 알림` 은 연습 파일을 넣은 뒤 학습지 서버에서 지난 버전 HTML 셋(요금제·기능 소개·새 소식)을 받아 `지난 버전` 폴더에 넣어요. 학습지 서버가 그날 타입캐스트 페이지를 받아 몇 군데를 바꾼 사본이에요. 남의 페이지라 이 레포에는 싣지 않았어요. 그 폴더에 이미 파일이 있으면 받지 않아요. 학습지로 새로 보내는 것은 없어요.

단어장 2-19 에서는 영화·미드 자막을 받는 MCP 서버를 프로젝트 폴더에 넣어요. 자막은 Stremio 의 OpenSubtitles 애드온에서, 작품 목록은 Cinemeta 에서 받아요. 그곳에는 찾은 작품 제목과 시즌·회차만 가요. 학습지로는 아무것도 보내지 않아요.

도우미는 스스로 새 판을 받아요. Claude Code 세션을 열 때(10분에 한 번까지) 이 레포의 최신 커밋을 GitHub 에 묻고, 새 판이 있으면 Claude Code 로 업데이트해요. 마켓플레이스 자동 업데이트를 꺼 두어도 받아요. GitHub 에는 아무것도 보내지 않아요.

도우미는 학습지 폴더에서만 일해요. 1권 1부는 홈 폴더의 `claude-practice`, 그 밖에는 `/시작` 을 한 폴더예요. 2권 폴더 안에는 도우미의 파일을 두지 않고, `/시작` 을 한 폴더의 경로를 `~/.workbook-tutor/` 에 적어 알아봐요.

## 학습지로 보내는 것

| 보내는 것                  | 무엇                                                                                        |
| -------------------------- | ------------------------------------------------------------------------------------------- |
| 단계 번호와 그때           | 도우미가 본 단계, `/막혔어`·`/시작` 을 쓴 장                                                |
| 세션을 열고 닫은 때        | 학습지가 「연결됨」을 띄워요                                                                |
| 모델 이름과 권한 모드      | 바뀔 때만 보내요                                                                            |
| 오류가 난 장               | 클코의 답이 오류로 끝났을 때 하던 장이에요                                                  |
| Claude 계정 ID 의 해시     | 되돌릴 수 없게 바꾼 값이에요                                                                |
| 도우미 판                  | 도우미 스크립트를 가리키는 12자예요. 판이 바뀌면 다시 보내요                                |
| 연습 메일을 받을 메일 주소 | `/연습문의`·`/연습청구` 에 쓴 주소예요. 학습지 서버가 메일을 보내는 데만 쓰고 남기지 않아요 |

내가 보낸 문장, 클코의 답, 파일 이름과 내용, 계정 ID 와 이메일은 보내지 않아요. 늘 도는 프로그램도 없어요. Claude Code 가 부를 때와 새 판을 받을 때만 잠깐 돌아요.

학습지에서 「대화 기록 보내기」에 동의했을 때만, 학습지 폴더에서 연 세션의 대화 기록을 보내요. 클코가 답을 마칠 때마다 새 줄만 보내고, 그림은 빼요. 학습지 목차 첫 화면의 계정 메뉴에서 끄면 바로 멈추고 보낸 기록도 지워져요.

## 컴퓨터에 남는 것

| 자리                               | 무엇                                                                                                                                                                                      |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `~/.workbook-tutor/`               | 도우미의 기록과 학습지 계정의 연결 토큰, 2권에서 `/시작` 을 한 폴더의 경로. `/질문` 이 찾는 학습지 원고 사본과 학습지 폴더 세션의 대화 기록 파일 경로도 여기 둬요. 이 컴퓨터에서만 읽어요 |
| 프로젝트 폴더의 `.workbook-tutor/` | 1권 2부 프로젝트의 진도, 미리보기·자막 서버. Mac 에서는 잠겨 있어요                                                                                                                       |
| `~/.local/node/`                   | `/시작` 이 깐 Node.js. 이미 있었으면 깔지 않아요. 셸 설정에 경로 한 줄을 더해요                                                                                                           |
| `~/Library/Fonts/`                 | `/시작 발표 자료` 가 넣은 글꼴 Pretendard 두 개. 이미 있었으면 넣지 않아요                                                                                                                |
| `~/.local/gh/`, `~/.local/bin/gh`  | `/시작 3권` 이 깐 GitHub CLI. 이미 있었으면 깔지 않아요. 셸 설정에 경로 한 줄을 더해요                                                                                                    |
| 뉴스 클리핑 폴더의 `.git/`         | `/시작 3권` 이 만든 저장소. 내 작업 기록이라 도우미를 지워도 남겨 둬요                                                                                                                    |

## 지우기

1. Claude Code 에서 `/plugin` 으로 workbook-tutor 를 지워요.
2. 남은 폴더를 지워요. Mac 은 터미널에서:

   ```bash
   chflags -R nouchg ~/.workbook-tutor <프로젝트 폴더>/.workbook-tutor
   rm -rf ~/.workbook-tutor <프로젝트 폴더>/.workbook-tutor
   ```

   Windows 는 PowerShell 에서:

   ```powershell
   Remove-Item -Recurse -Force ~\.workbook-tutor, <프로젝트 폴더>\.workbook-tutor
   ```

`samples` 의 글과 그림은 연습용으로 직접 만들었어요. 계좌·기록·숫자와 2권 3부 예시의 사람·회사는 지어낸 것이에요. `/연습청구` 의 금액과 날짜도 지어낸 것이고, 서비스 이름만 실제 이름을 글자로 썼어요. 경쟁사 알림이 지켜보는 타입캐스트만 실제 회사예요. 발표 자료의 글꼴은 Pretendard(SIL Open Font License)예요. 뉴스 클리핑의 기사 제목과 링크는 구글 뉴스 RSS 에서 받은 실제 기사이고, 요약과 나머지 파일은 직접 썼어요.
